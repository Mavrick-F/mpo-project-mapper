# Changelog

## Documentation — 2026-10-22

- Added a screenshot of an example corridor and its analysis results.
- Clarified the project's origin and made the public demo easier to find.

## v3.1

- Enabled GitHub Pages for the public demo, deployed from `master` (`/` root, no build step needed).
- Switched the default basemap from CartoDB Voyager to OpenStreetMap standard tiles, since CARTO now requires an API key for its raster basemaps. No API key is needed with the new default.

## v3.0 - Initial Public Release

- Consolidated user documentation into `README.md` and `GUIDE.md`.
- Included sample MPO datasets and configuration templates for adapting the tool to other regions.
- Added client-side spatial analysis, PDF reporting, configuration validation, and smoke tests.
